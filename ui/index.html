BTC Keytool

offline · nothing is ever broadcast

Derive the public key and every address from a private key. A key owns all five addresses at once.

Inspect an address (script, type, dust limit) or a public key (every address it controls).

Create a k-of-n multisig address from the cosigners' public keys. Only public keys are needed here. Every cosigner should build it independently and compare the address before funding it.

Build a transaction from a JSON spec and sign it with the keys in the spec. If signatures are still missing (multisig, or no key given) you get a PSBT to pass on instead of a transaction.

Add your signature to a partially signed transaction. The first press of Sign shows what it pays; check the outputs and the fee, then press Sign again: you are authorising exactly that payment.

Merge PSBTs of the same transaction that cosigners signed separately.

Verify every signature of a signed transaction or a PSBT. Valid signatures do not mean the payment is the one you intended: check the outputs and fee shown. A raw transaction needs the spec it was built from, because signatures commit to the amounts being spent and the transaction does not contain them.

Decode a raw transaction or a PSBT.

Sign a text message with a key, or check someone else's signature. A signature is verified before it is shown.
